# BioImageFlow Platform

BioImageFlow Platform is a desktop application for building, executing, and inspecting bioimage analysis workflows visually.
It combines a Vue node-based editor with a FastAPI backend and the [BioImageFlow](https://github.com/Inria-SAIRPICO/bioimageflow) workflow library.

For installation, local development, architecture, and workspace behavior, see the [project README](https://github.com/Inria-SAIRPICO/bioimageflow-platform#readme).
